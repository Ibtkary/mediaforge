دليل تفاعلي متقدم

افهم واكتشف قوة Mediastore

ليس مجرد مكتبة لرفع الصور، بل نظام متكامل ذكي صُمم لمعالجة، ضغط، إيقاف التكرار، وتقديم الصور للمستخدمين بسرعة البرق عبر الـ Cloud. لنأخذك في رحلة لتعرف كيف يعمل.

الخطوة الأولى

الاستقبال والفحص الأمني

تبدأ الرحلة عندما يقوم المستخدم (عبر تطبيق Flutter) باختيار صورة وإرسالها إلى الـ API الخاص بك. هنا تتدخل مكتبة Mediastore لتلعب دور حارس الأمن.

نوع الملف الحقيقي MIME Type Validation

النظام لا يثق بامتداد الملف (مثل .jpg). بل يقوم بقراءة محتوى الملف الفعلي ليتأكد أنه صورة حقيقية وآمنة، وليس ملفاً خبيثاً متنكراً.

الحد الأقصى للحجم Size Capping

يتم الفحص المبدئي لحجم الملف لمنع استهلاك ذاكرة الخادم (Memory Exhaustion) إذا حاول أحدهم رفع ملف ضخم جداً.

الخطوة الثانية

الذكاء في المعالجة

بعد التأكد من أمان الصورة، تبدأ عملية تحسينها. النظام لا يحفظ الصورة كما هي أبداً، بل يحولها للنسخة الأكثر كفاءة.

البصمة الرقمية للمنع التكرار Content Hash (Dedup)

عبر خوارزمية SHA-256، نصنع "بصمة" للصورة. إذا رفع المستخدم نفس الصورة مرتين، المكتبة تكتشف ذلك برمجياً وتتخطى الرفع لتوفير المساحة والتكاليف.

التحويل للصيغة الحديثة WebP Encoding

يتم تحويل صيغ (JPEG, PNG) إلى WebP. النتيجة؟ حجم أصغر بنسبة تصل لـ 88% مع الحفاظ التام على جودة الصورة الأصلية. توفير هائل في الـ Bandwidth.

الخطوة الثالثة

خلق النسخ (Variants)

صفحة تفاصيل المنتج تختلف عن قائمة البحث المصغرة. لماذا نجبر التطبيق على تحميل صورة بدقة 2000 بيكسل لعرض أيقونة صغيرة؟

النسخ المتعددة Image Variants

تقص المكتبة الصورة تلقائياً لـ 4 أحجام مدروسة:
• Thumb (150px): فائقة الخفة للقوائم.
• Medium (400px): لكروت المنتجات.
• Large (800px): لتفاصيل المنتج.
• Original: للعرض بملء الشاشة وتكبير التفاصيل.

تخطي النسخ الذكي Smart Variant Skip

إذا تم رفع صورة صغيرة جداً (مثلاً 100 بيكسل)، النظام ذكي بما يكفي لعدم إنشاء نسخ (Large و Medium) لأنها بلا فائدة!

الخطوة الرابعة

الرفع والحفظ السحابي

الآن أصبحت لدينا 4 ملفات WebP خفيفة للغاية وجاهزة للرفع. تقوم المكتبة بنقلها بأمان إلى السحابة.

التخزين السحابي Cloud Storage (S3 / Bunny)

ترسل الملفات إلى خوادم تخزين مخصصة (مثل AWS S3 أو Bunny). قاعدة البيانات الخاصة بك (DB) لا تحفظ الصور نهائياً، بل تحفظ فقط "رابط السحابة" (Storage Path) لتقليل العبء على الخادم.

منظومة الإعادة التلقائية Retry Mechanism

لو انقطع الاتصال للحظة مع السحابة أثناء الرفع، المكتبة تقوم بالمحاولة مجدداً (Retries) بصمت لضمان عدم ضياع عمل المستخدم.

الخطوة الخامسة

التوصيل السريع والآمن

عندما يفتح المستخدم التطبيق ويريد رؤية المنتجات، نحن لا نعطيه الرابط المباشر للمخزن ابداً.

شبكة التوصيل السريع CDN Delivery

يتم تقديم الصور من (Content Delivery Network)، وهي أجهزة كمبيوتر موزعة حول العالم. لتصل الصورة للمستخدم من السيرفر الأقرب له جغرافياً في أجزاء من الثانية.

الروابط الآمنة المؤقتة Signed URLs

المكتبة تولد روابط مشفرة تنتهي صلاحيتها (مثلاً بعد ساعة). إذا تم اختراق بيانات التطبيق، الروابط المسروقة ستصبح بلا قيمة لأنها منتهية الصلاحية.

كيف تكتب الكود؟

التكامل مع Mediastore مصمم ليكون نظيفاً ومباشراً ولا يسبب تلوثاً في بنية (Clean Architecture) الخاصة بك.

1. الإعداد المبدئي (media/client.go) 
package media

import (
    "os"
    "github.com/Ibtkary/mediaforge"
)

// تهيئة العميل مرة واحدة عند اقلاع السيرفر
func NewClient() (*mediaforge.Client, error) {
    return mediaforge.New(mediaforge.Config{
        StorageZone:    os.Getenv("BUNNY_ZONE"),
        StorageAPIKey:  os.Getenv("BUNNY_API_KEY"),
        CDNBaseURL:     os.Getenv("BUNNY_CDN_URL"),
        CDNSecurityKey: os.Getenv("BUNNY_CDN_KEY"),
    })
}
2. رفع الصورة وحفظها (service/image_service.go) 
func (s *ImageService) UploadProductImage(ctx context.Context, tenantID string, data []byte) (*ProductImage, error) {
    // 1. المكتبة تقوم بكل السحر (Validate, Hash, Convert, Resize, Upload)
    asset, err := s.media.Upload(ctx, tenantID, data)
    if err != nil {
        return nil, fmt.Errorf("upload processing failed: %w", err)
    }

    // 2. نحفظ البيانات الوصفية (الرابط والأبعاد) في قاعدة البيانات الخاصة بنا
    img := &ProductImage{
        StoragePath: asset.StoragePath, // الرابط النسبي في السحابة
        ContentHash: asset.ContentHash, // لحماية النظام من التكرار
        Variants:    asset.Variants,    // مسارات وخيارات الأحجام المختلفة
    }
    s.repo.Save(ctx, img)

    return img, nil
}
3. توليد روابط العرض (API Layer) 
func (s *ImageService) GetProductImageURLs(storagePath string) (*mediaforge.SignedURLSet, error) {
    // توليد روابط لكل الأحجام صالحة لمدة ساعة واحدة فقط لأمان صارم
    return s.media.GetSignedURL(
        storagePath, 
        []string{"thumb", "medium", "large"}, 
        1 * time.Hour,
    )
}
